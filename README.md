# 🧠 Abnormal Psychology: Premium Interactive eBook

An immersive and visually rich educational eBook built entirely with HTML and CSS.

---

## 📖 About

This project explores major concepts in abnormal psychology through:

- Anxiety Disorders
- Depression
- Bipolar Disorder
- Schizophrenia
- Personality Disorders
- Brain Function & Neurobiology
- Clinical Case Studies
- Interactive Review Questions

Designed as a premium reading experience rather than a traditional website.
